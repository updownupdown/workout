# Flow

Auto-built follow-along workouts: yoga, strength, pilates, core, stretching and breathwork. Pick a time and a focus, then just follow the animated figure and the voice. Installable PWA, works offline, no accounts, no health data.

Live: https://updownupdown.github.io/workout/

```bash
npm install
npm run dev      # http://localhost:5173/workout/
npm run build
```

Open `/?poses` in dev to see a contact sheet of every keyframe in the move library.

See [docs/PLAN.md](docs/PLAN.md) for the product plan and the visual approach.
